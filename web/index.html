      Good to know

      Chrome extension
      1. Open chrome://extensions and turn on Developer mode.
      2. Choose Load unpacked and select Pawket’s extension folder.
      3. Click the Ready button at the top right of this page and copy the pairing code.
      4. Open the extension, open Connection, and paste the code.

      After that, right-click any link, video or image and choose Save with Pawket.

      The extension comes with Pawket. It isn’t in the Chrome Web Store.

      AI agents

      Add Pawket to any AI app that supports MCP. Point it at the Pawket program on your computer, like this:

      {
  "mcpServers": {
    "pawket": {
      "command": "/absolute/path/to/pawket",
      "args": ["mcp", "--output", "/your/downloads"]
    }
  }
}

      Your agent can then look up a link and save one of the files it finds.

      What works

      Save public X videos, GIFs and photos, direct media links, and media exposed by ordinary web pages.

      Pick Video or Audio, then the quality. Video comes with or without sound, and “Plays everywhere” converts it to H.264 so any player opens it. Audio comes as the original track, MP3 (320, 192 or 128 kbps), WAV, FLAC or Opus. These choices need FFmpeg; with yt-dlp configured, YouTube, TikTok, SoundCloud, Vimeo, playlists and many more sites work too.
